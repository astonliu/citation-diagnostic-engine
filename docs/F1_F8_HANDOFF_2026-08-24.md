## The F1 trap — read this before reporting any F1 number

`confirm.fully_answered` is an **all-three** gate: PubMed AND Crossref AND OpenAlex must each return a
real score before `decide()` may license an F1. Its docstring: *"An accusation of fabrication asserts
that the work is in no database; that assertion requires every database to have actually been
consulted."*

Two `provider_probe.json` files from the same 2026-08-24 run, same probe title:

| probe | pubmed | crossref | openalex | `fully_answered` |
|---|---|---|---|---|
| earlier | 36.22 | 74.07 | **100.0** | **True** |
| later | 36.22 | 74.07 | **None** | **False** |

PubMed and Crossref were byte-identical across both, so the probe is deterministic and OpenAlex is the
only moving part. OpenAlex metered its API in 2026: **no key = $0.10/day**, **free key = $1/day**; a
`list + filter` call costs $0.0001, a `search` call $0.001
(`developers.openalex.org/guides/authentication`, `help.openalex.org/access/example-costs/`, read
2026-08-24). The allowance ran out mid-run and every later reference was held.

**Fixed in `8f28bda`.** ZD has an `OPENALEX_API_KEY`. The notebook now probes **before AND after** each
batch and sets `F1_REPORTABLE` only when the before-probe passes, the after-probe passes, and the
confirm leg logged **zero 409s** (`openalex_telemetry`). **If that gate is False, record F1 as
NOT ATTEMPTED for those papers, never as zero.** F8 never calls `confirm()` and is unaffected.

### Three OpenAlex legs, and only one gates F1

| leg | file | tier | volume | gates F1? |

| `search_openalex` | `confirm.py:160` | `filter=` $0.0001 | flagged survivors only | **YES** |

candidates are retrieved, which changes F2 and F1 outcomes. It is a judgment change, not a billing
change, and needs its own spec with a before/after diff.

## Four defects the authoring session shipped — do not repeat them

1. **Timestamped `RUN_NAME` forked the work.** Every Colab restart minted a new run directory the
   resume scan could not see. Four directories accumulated **331 paper-runs for 174 distinct papers** —
   roughly 47% of the $5.18 bought work that already existed. Fixed: `RUN_NAME` is now
   `f1f8_only_seed<SEED>_n<N>`, deterministic.
2. **Google Drive in the hot loop.** `path.exists()` per reference and an `os.fsync` per HTTP event, on
   a FUSE mount, from 24 threads. The cell printed nothing for 18 minutes. Fixed: hot paths on
   `/content/cre_fast`, `rsync` to Drive on a 300 s timer. This was already documented in
   `MASS_RUN_NOTEBOOK_2026-08-22.md` item 8 and was not carried over.
3. **Code written against an unread API.** `openalex_telemetry.delta()` returns
   `{"legs": {...}, "leg_totals": {...}, "total": n, "quota_exhausted": n}`; the notebook assumed
   `{leg: {status: n}}` and raised `AttributeError` in the heartbeat and in the exit gate — which would
   have destroyed the F1 reportability verdict at the end of a completed batch. Fixed.
4. **A cell whose first output was gated on work completing** is indistinguishable from a hang. Fixed:
   Section 5C prints on entry and a watchdog thread prints every 15 s regardless; Section 6 prints one
   line per paper and a heartbeat every 10 s.

**Standing rule for the next session: read or run the actual code before shipping anything against it.
Do not infer a return shape from a docstring.**

## Locked constraints this work must not violate

- Naturally-occurring data only for gold; never hunt the gold set. Calibration may be hunted.
- **Never use the detector's own flags as gold.**
- Claude assigns no semantic labels and curates no ground truth.
- **Never pool frames.** Three F1 denominators now exist under three conditions — the 2026-08-23
  overnight run (2,074 refs, unkeyed), the 2026-08-24 partial (8,009 refs, unkeyed), and the keyed run.
  Only the keyed one can carry an F1 number; none may be summed. DEC-083.

  to two-of-three for cost.
- F2 evaluation is precision-only; **F2 recall is non-negotiable in the matcher**.
- `SAME_WORK_VARIANT` uses `SAME_WORK_TITLE_SIM_MIN` in `cre/f1/biblio_match.py` — read the constant
  from the line, never from memory.
- `band_prompts.py` not edited; its blob OID is sealed into both frozen prompt packages.
- Path-based module loading; no `__init__.py` in `cre/`; **restart Colab after any push**.
- `author_match` tri-state: `None` is unknown; test with `is False`.
- No-rewrite discipline: targeted amendments only.
